# Mall Beer Counter

A retro pixel-hotel style drink tracker for the mall.

- **Map**: an isometric mall floor. Tap a spot to select it, or tap empty floor to add your own.
- **Log drinks**: pick the drink (beer, wine, cider, cocktail, spirits, non-alcoholic, pop, water) and size, and tag the friends you're with.
- **Rewards**: milestones unlock wearable items for your pixel character.
- **Wardrobe**: change your look and wear what you've unlocked.
- **History**: every drink by day, with size, place and friends. Undo is available for removals.

Single self-contained `index.html`, no build step. Open it in a browser or serve it with GitHub Pages. Data is saved in the browser's localStorage.
